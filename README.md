# Folia--MOD
把本地视频当作 Folia 播放页的背景循环播放；支持填充方式、压暗、模糊、播放速度、音量与随音乐暂停
## 设置项

# 视频背景 · Folia 模组

用本地视频当 Folia 播放页的背景，循环播放。背景之上照常渲染歌词动画，切换歌词模式、换歌都不影响。

纯 client 模组，没有 `main` 入口，不执行任何 Node 代码。

## 安装

1. 打开 Folia：**设置 → 实验室 → 模组系统**，把总开关打开。
   （默认关闭；关着的时候加载器根本不扫描目录，不会加载任何模组代码。）
2. 找到用户模组目录：模组面板右上角的「打开模组目录」按钮。打包版是
   `%APPDATA%\Folia\mods`。
3. 把整个 `video-background` 文件夹放进去，最终路径形如
   `%APPDATA%\Folia\mods\video-background\mod.json`。
4. 回到模组面板，找到「视频背景」，**启用并确认**。
   单个模组默认禁用，第一次启用会弹一个原生确认窗口，列出它声明的权限
   （这里只有 `filesystem.data`，用来记住你选的视频）。
5. 播放页 → 背景选择器 → 选 **视频背景** → 下面会出现设置面板，点 **选择视频…**。

> 也可以走命令面板搜「视频背景」，直接执行「选择视频背景 / 清除视频背景」，不用先切背景类型。

## 关于「确认」这一步

Folium 把模组当作**可信代码**，`permissions` 只是功能开关，不是沙箱。启用确认会和模组目录的内容
摘要（sha256）绑定：**改完任何文件，授权立即失效，模组回到禁用状态，需要重新确认一次**。
所以改了 `client.mjs` 之后记得重新启用。

## 设置项

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 填充方式 | 裁剪铺满 | `cover` 裁切填满 / `contain` 完整显示留黑边 / `fill` 拉伸 |
| 压暗 | 0.35 | 在视频上叠一层黑色，让歌词更好读；0 完全不压 |
| 模糊 | 0 | 背景失焦，前景更突出；开启时会轻微放大以免边缘发虚 |
| 播放速度 | 1 | 0.25×–2× |
| 音量 | 0 | 默认静音，避免和音乐打架 |
| 随音乐暂停 | 开 | 音乐暂停时视频跟着停；关掉则一直播 |
| 循环播放 | 开 | 关掉则播完停在最后一帧 |

## 已知行为 / 边界

- **导出与 OBS**：宿主在透明表面上不渲染背景，所以透明视频导出、OBS 源里不会带上视频背景——
  这正是想要的叠加效果（歌词透明输出，视频背景你自己在 OBS 里垫）。
- **静态预览**：背景选择器的预览只画一帧（契约要求 `staticMode` 下不动画），会 seek 到
  25% 处取一帧，避免第一帧是黑的。
- **文件访问**：模组始终拿不到文件路径。选中的文件由宿主换成 `folia-mod://_files/...` 会话句柄，
  支持 Range，能直接喂给 `<video>`。跨重启靠 `restoreFile(grantId)` 恢复；文件被移走或授权失效时
  会自动清掉记录，需要重新选一次。
- **多显示器 / 壁纸模式**：视频背景是画在播放页背景层的，和 Folia 的桌面壁纸模式互不冲突，
  壁纸模式下同样生效（除非该平台的透明窗口把你垫的桌面透出来）。

## 契约依据

按 Folium **1.4** 写的，用到的都是稳定接口：

- `folium.registries.backgrounds.register(...)`（`FoliumBackgroundDef`）
- `folium.registries.commands.register(...)`
- `folium.ui.pickFile / restoreFile / releaseFile`
- `folium.storage`
